=============================================================================
   GUIA DE EXECUÇÃO E DE REDE - JOGO DE DIGITAÇÃO INFANTIL (ALFABETIZAÇÃO)
=============================================================================

Este documento contém todas as instruções necessárias para subir o jogo educativo na sua infraestrutura utilizando o Docker e obter o endereço IP do seu notebook/computador host para que outras pessoas de sua rede interna (tablets, smartphones ou outros computadores) também acessem instantaneamente.

-----------------------------------------------------------------------------
1. PRÉ-REQUISITOS
-----------------------------------------------------------------------------
- Ter o Docker instalado na sua máquina.
- Ter o comando docker-compose (ou plugin `docker compose` v2) instalado.

-----------------------------------------------------------------------------
2. ESTRUTURA DOS ARQUIVOS DE DEPLOY
-----------------------------------------------------------------------------
Certifique-se de que os arquivos de execução estão na mesma pasta:
├── Dockerfile          (Multi-stage build Node.js + Nginx Alpine)
├── Dockerfile.txt      (Modelo de referência do Dockerfile validado)
├── docker-compose.yml  (Mapeamento de portas e serviço)
├── .env                (Definição da porta host APP_PORT)
├── index.html          (Interface e suporte estático)
├── public/             (Contém yolo-worker.js do Robozinho IA)
├── src/                (Código-fonte React/TypeScript do jogo)
├── README.md           (Documentação e descrição das funcionalidades)
└── INSTRUCOES.txt      (Guia de execução e configuração de rede)

-----------------------------------------------------------------------------
3. COMO EXECUTAR O JOGO VIA DOCKER
-----------------------------------------------------------------------------
Abra o seu terminal (Prompt de Comando ou PowerShell no Windows / Terminal no Linux e macOS) na pasta onde estão estes arquivos e execute os comandos abaixo:

A) Buildar e Subir o container (em primeiro plano de logs):
   $ docker-compose up --build

B) Executar o container em segundo plano (em Background / modo Daemon):
   $ docker-compose up -d --build

C) Para verificar se o container está de pé e rodando na rede:
   $ docker ps

D) Para parar a execução e desligar o container:
   $ docker-compose down

-----------------------------------------------------------------------------
4. COMO CONFIGURAR A PORTA DE ENTRADA
-----------------------------------------------------------------------------
Por padrão, o arquivo `.env` mapeia a porta host como 8080 (APP_PORT=8080).
Se você quiser acessar o jogo diretamente sem colocar a porta no final 
(ex: apenas http://192.168.1.10 ao invés de http://192.168.1.10:8080), você pode
editar o seu arquivo `.env` e alterar a variável para a porta HTTP padrão (80):
   APP_PORT=80

Salve o arquivo .env e reinicie o container (`docker-compose down && docker-compose up -d`).

-----------------------------------------------------------------------------
5. DESCOBRINDO O IP DO SEU NOTEBOOK/HOST NA REDE LOCAL
-----------------------------------------------------------------------------
Para que outros aparelhos na sua rede Wi-Fi encontrem o jogo do seu notebook, você precisa descobrir o endereço IPv4 dele. Siga as instruções do seu Sistema Operacional:

■ NO WINDOWS:
  1. Pressione as teclas [Windows] + [R] juntas para abrir a caixa "Executar".
  2. Digite "cmd" e tecle Enter para abrir o Prompt de Comando do Windows.
  3. No prompt, digite o seguinte comando e aperte Enter:
     > ipconfig
  4. Procure pela sua conexão ativa de internet de acordo com sua interface:
     - Se estiver usando internet sem fio: procure por "Adaptador de Rede Sem Fio Wi-Fi".
     - Se estiver usando cabo de rede: procure por "Adaptador Ethernet".
  5. Identifique a linha que diz "Endereço IPv4". Ela terá um formato como:
     "192.168.X.X" ou "10.0.X.X" (Por exemplo: 192.168.1.15)

■ NO WINDOWS (WSL2 + DOCKER NO UBUNTU):
  Se o seu Docker está rodando diretamente de dentro do Ubuntu no WSL2 (Windows Subsystem for Linux), o Windows 11 roda o Ubuntu em uma "Máquina Virtual" com uma placa de rede privada (NAT). Isso faz com que celulares e tablets não consigam acessar o IP do Windows diretamente por padrão.
  
  Para consertar isso perfeitamente no Windows 11 Pro, existem DUAS opções ótimas:

  OPÇÃO A: MODO ESPELHADO (Mirrored Mode - Recomendado e mais simples para Windows 11)
  1. No Windows, pressione as teclas [Windows] + [R] para abrir o "Executar".
  2. Digite `%USERPROFILE%` e clique em OK. Isso abrirá a pasta do seu usuário do Windows.
  3. Procure por um arquivo chamado `.wslconfig`. Se ele não existir, crie um arquivo texto e renomeie EXATAMENTE para `.wslconfig` (remova o `.txt` do final).
  4. Abra este arquivo no Bloco de Notas e cole o bloco a seguir:
     ```ini
     [wsl2]
     networkingMode=mirrored
     ```
  5. Salve o arquivo e feche-o.
  6. Feche o Ubuntu, abra o PowerShell do Windows como Administrador e execute para reiniciar o WSL:
     > wsl --shutdown
  7. Abra o Ubuntu WSL novamente e suba o Docker (`docker-compose up -d`). Agora as portas do Docker no Ubuntu são fundidas totalmente com as de rede do Windows, de modo que basta acessar o endereço IPv4 regular do seu notebook Windows pelo seu celular!

  OPÇÃO B: PORTERING (Redirecionamento usando netsh e liberando o Firewall)
  Se preferir manter a configuração de rede padrão:
  1. Descubra o IP interno do Ubuntu WSL digitando no terminal do Ubuntu:
     $ hostname -I
  2. Abra o PowerShell do Windows como ADMINISTRADOR e execute os comandos abaixo (substitua o IP pelo do seu Ubuntu):
     > netsh interface portproxy add v4tov4 listenport=8080 listenaddress=0.0.0.0 connectport=8080 connectaddress=172.20.15.5
     > New-NetFirewallRule -DisplayName "Docker WSL2 8080" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8080
  3. Agora, use o IP real do Windows para acessar o jogo dos celulares e tablets.

■ NO LINUX:
  1. Abra o Terminal do Linux.
  2. Execute o comando simples abaixo para obter os IPs válidos instantaneamente:
     $ hostname -I
  3. Seu endereço IPv4 privado geralmente começará com "192.168." ou "10." (ex: 192.168.0.22).

■ NO MACOS:
  1. Vá em Ajustes do Sistema > Rede > Selecione Wi-Fi / Ethernet Ativa > Detalhes > Endereço IP.
  2. Alternativamente, pelo Terminal do Mac:
     $ ipconfig getifaddr en0

-----------------------------------------------------------------------------
6. ACESSANDO O JOGO EM OUTROS DISPOSITIVOS (TABLETS, SMARTPHONES, ETC)
-----------------------------------------------------------------------------
Garante-se que todos os dispositivos estejam conectados exatamente na mesma rede Wi-Fi/Rede local que o seu notebook.

Acesse o navegador (Chrome, Safari, Firefox) de qualquer dispositivo e digite na barra de endereços o IP que você encontrou na Seção 5, seguido pela porta definida no arquivo `.env`:

   Exemplo com a porta do .env configurada como 8080:
   http://192.168.x.x:8080

   Exemplo com a porta do .env configurada como 80:
   http://192.168.x.x

-----------------------------------------------------------------------------
7. CONTEÚDO DOS ARQUIVOS DE CONFIGURAÇÃO (MODELO VALIDADO)
-----------------------------------------------------------------------------

■ Dockerfile (Multi-stage Build com Node.js + Nginx Alpine)
-----------------------------------------------------------------------------
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci || npm install
COPY . .
RUN npm run build

FROM nginx:alpine
LABEL maintainer="Suporte Tecnico <suporte@exemplo.com>"
RUN rm -rf /usr/share/nginx/html/*
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
-----------------------------------------------------------------------------

■ docker-compose.yml
-----------------------------------------------------------------------------
version: "3.8"

services:
  jogo-digitacao:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: jogo_digitacao_infantil
    restart: always
    ports:
      - "${APP_PORT:-8080}:80"
    environment:
      - NODE_ENV=production
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
-----------------------------------------------------------------------------

■ .env
-----------------------------------------------------------------------------
APP_PORT=8080
